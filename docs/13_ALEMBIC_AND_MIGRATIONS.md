# Alembic migrations

Run Alembic from backend/. alembic/env.py loads .env, constructs its SQLAlchemy URL from database variable names, imports Base/models, and exposes Base.metadata as target_metadata. It supports online and offline migration functions.

The visible revision history starts with 6931a1f55fc1 baseline schema, then adds wallet transactions, user identities, redesigned orders/executions, order events/lifecycle, watchlists, order constraints, reservations, immutable execution refs, stop triggers, paper accounting, and immutable order events.

Typical commands:

~~~text
alembic upgrade head
alembic current
alembic revision --autogenerate -m "describe change"
~~~

Autogenerated migrations must be reviewed before applying. Migrations, not only current models.py, are what update existing databases.
